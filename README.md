# strata-metodo — the observation method of Strata Observatory, every version

*Español más abajo.*

This repository holds **every version of the observation method**, as it was closed. Each
sealed day of the archive carries inside it the full text of the method that governed it.
Here that same text has a stable address.

- **Only closed versions.** A version is published after the first day it governs has
  been sealed, never before.
- **None is rewritten.** A new version is a new file and a new row. For the versions that
  governed sealed days, the file holds **the bytes that were sealed**, so its SHA-256 is
  the hash of the method text in any sealed day it governed.
- **The Spanish text is the one that is sealed.** The English files are translations: not
  sealed, and the Spanish text prevails.

## En español

Este repositorio guarda **todas las versiones del método de observación**, tal como se
cerraron. Cada día sellado del archivo lleva dentro el texto completo del método que lo
gobernó. Aquí ese mismo texto tiene una dirección estable.

- **Sólo versiones cerradas.** Una versión se publica después de sellarse el primer día
  que gobierna, nunca antes.
- **Ninguna se reescribe.** Una versión nueva es un fichero nuevo y una fila nueva. En
  las versiones que gobernaron días sellados, el fichero contiene **los bytes que se
  sellaron**, así que su SHA-256 es el del texto del método en cualquier día sellado que
  gobernó.
- **El texto que se sella es el español.** Los ficheros en inglés son traducciones: no
  están sellados, y manda el español.

La tabla de arriba dice, para cada versión, qué días gobierna en este archivo. Las
versiones 1 a 3 se publican para que este archivo no esconda su propia historia: la
tabla de versiones del método las cita, y quien vea que la primera sellada es la 4 tiene
derecho a saber qué decían las anteriores. La 3 rigió un archivo de ensayo, desechado,
del 2026-08-31 al 2026-09-02; la 1 y la 2 no rigieron nunca un día observado.
